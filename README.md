# 🌍 City Weather API (.NET 8)

A clean and simple ASP.NET Core Web API that returns **current weather and air quality information** for a given city using the **OpenWeatherMap API**.

---

## ✨ Features

- Get current **temperature (°C)**
- **Humidity (%)**
- **Wind speed (m/s)**
- **Air Quality Index (AQI)**
- Major air pollutants (PM2.5, CO, NO2, etc.)
- City **latitude & longitude**
- Clean architecture and testable services
- Unit tests using **xUnit, Moq, FluentAssertions**

---

## 🛠️ Tech Stack

- **.NET 8 / ASP.NET Core Web API**
- **HttpClient**
- **OpenWeatherMap API**
- **xUnit** (Unit Testing)
- **Moq** (Mocking)
- **FluentAssertions**
- **Swagger / OpenAPI**
